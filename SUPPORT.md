# Support

Before asking for help:

1. Read the installation and troubleshooting sections in the README.
2. Restart Home Assistant after installing or updating the integration.
3. Check **Settings → System → Logs**.
4. Confirm the Home Assistant and Pool Pilot versions.

For reproducible bugs, open a GitHub issue using the bug report form. Include logs with secrets and personal data removed.

General feedback and usage discussions can be posted in the Home Assistant community topic dedicated to Pool Pilot.
