# Security Policy

## Supported versions

Security corrections are provided for the latest stable release. Users should update before reporting a security issue.

## Reporting a vulnerability

Do not open a public GitHub issue for a vulnerability. Use GitHub's private security advisory feature when available, or contact the maintainer privately through the GitHub profile.

Please include:

- the affected version;
- a clear description of the issue;
- steps to reproduce;
- the potential impact;
- any proposed mitigation.

Please allow a reasonable amount of time for investigation before public disclosure.
