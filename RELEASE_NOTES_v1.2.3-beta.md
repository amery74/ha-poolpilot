# Pool Pilot v1.2.3-beta

Version corrective sans modification de la structure générale de la carte.

- Ajout du bouton Mode Maintenance dans le Mode Expert.
- Réduction de la valeur ORP / chlore dans la jauge pour éviter les débordements.
- Déplacement de la barre de progression dans la ligne « Cycle du jour » du Mode Expert.
- Retrait de la configuration et des services du volet dans l’intégration : le volet est désormais géré uniquement par la carte.

### Correctif recommandations
- Une recommandation produit est désormais exposée comme alerte principale lorsqu'aucune autre alerte Pool Pilot n'est prioritaire.
- Le dosage, le motif et les consignes après traitement sont transmis à la carte.
